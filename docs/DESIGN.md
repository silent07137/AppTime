# Android v1.0.0 界面设计

目标：第一眼看清累计，第二步找到应用；默认导入最早可用历史，减少操作与常驻说明。使用原生 Compose，不引入图表/图标库、网络字体或位图素材。

## 视觉

- 浅色：背景 `#F5F7F4`、卡片 `#FEFFFC`、重点色 `#176B5B`、累计卡片 `#DDF2E8`。
- 深色：背景 `#141C18`、卡片 `#1D2721`、重点色 `#99D8BE`、累计卡片 `#244B3F`。
- 20dp 页面边距，20/28dp 圆角，25sp 标题、38sp 累计；次要信息降低对比。
- 系统应用图标，未解析到时首字符占位；导航和功能图标使用简单矢量线条。

## 信息层级

| 页面 | 默认可见 | 展开/进入后可见 |
|---|---|---|
| 总览 | 总计、新记录/旧历史、更新、前五排行、7 天记录 | 来源、范围、起点和缺口 |
| 应用 | 搜索、名称/图标、累计时长条 | 包名、来源、每日记录 |
| 趋势 | 7 天细粒度图表和日期记录 | 时区与旧汇总不能拆分的原因 |
| 设置 | 权限、全部历史重读、版本 | 来源/覆盖、隐私与保存、GPL |

缺失日期显示“—/未采集”；不以演示值填补，不把旧汇总伪造为精确每日记录。排行时长条相对第一名，不是一天占比。

刷新/返回有可访问名称；列表名称允许截断，详情显示全名；页面可滚动。实机检查浅/深色和 1.3 字体倍率，其他屏幕与完整 TalkBack 流程尚未全部验收。
