# AppTime v1.0.0

Android 原生应用累计时长档案，GPLv2，Android 10 及以上。

## 本次交付

- 开启使用情况访问后，默认自动读取系统保留的最早汇总，不需要先选择天数。
- 重新设计总览、排行、应用详情、7 天趋势与设置。浅/深色主题、真实应用图标、时长对比和搜索；来源/缺口说明收进详情。
- 已记录、可追溯旧历史和已知总计分开展示。完整系统汇总与重叠会话不重复计算，旧日数据被较宽汇总覆盖时保留原始观测，只计一份。
- Room 本地保存、显式升级迁移；启动采集与后台每 6 小时尝试。没有网络权限、账号、广告、分析 SDK 或常驻服务。

下载 `AppTime-v1.0.0.apk`（约 2.6 MB），安装后按页面开启系统使用情况访问。`SHA256SUMS.txt` 可用于校验文件；对应源码见本 Release 的 v1.0.0 标签。

## 验证

21 项核心测试和 17 项设备测试通过，含真实系统来源、历史去重和迁移。Debug/Release lint 均为 0 错误、6 项非阻断提示。Release 已在 Android 16 测试机覆盖安装、启动和检查 UI，原档案与权限保留。详细结果见仓库验证文档。

## 当前边界

系统只提供仍保留的数据，不能保证从安装日起全部历史；返回起点可能是汇总边界，前台时间不等于操作时间。历史完整性和原始时区未知，跨越建立时间的完整汇总可能包含建立后的时间。趋势不把旧汇总伪造为每日明细。

**此版尚无备份。卸载 AppTime 或清除数据会丢失本机档案。** 加密备份/恢复、Windows、WebDAV、跨设备、分类及手动调整留待后续阶段。本版为 Android 本机统计交付，不代表开发手册所有阶段完成。长期后台和所有厂商行为尚未验收。
