# AppTime v1.1.0

修复“已记录”在系统历史刷新后归零的问题：现从已保存的前台事件独立重建并持续保存，升级旧档案时会回填，关闭重开不会清空。已记录与旧历史可能重叠；“已知总计”继续去重，不能把两项直接相加。

应用详情和最近 7 天趋势现在读取系统可用的逐日使用时长；系统没有返回某应用某天时，显示已采集事件的日汇总。更早的宽范围历史无法可靠拆到每天，仍只进入累计。

设置新增“关于 AppTime”，包含 GitHub 仓库、GPLv2 正文和第三方许可证；总览、应用、趋势、设置及详情/关于之间加入轻量淡入淡出。

Android 10+；安装 `AppTime-v1.1.0.apk` 可覆盖 v1.0.0 并保留本机档案。此版仍无备份；卸载或清除数据会丢失档案。系统保留范围决定能补回多少旧日期，不能保证完整历史。
