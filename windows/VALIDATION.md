## 计时和数据

Actions 桌面自检在存在可读前台窗口时，单独核对本程序真实前台会话已保存且时长为正；合成排行数据不能作为采集通过的依据。自检在独立档案关闭空闲阈值以验证采样，普通使用仍默认 5 分钟。没有可读前台时明确报告未验收。

每秒采样，前台切换边界最多约一个采样周期的误差；每 15 秒及切换/暂停/正常退出保存事务检查点。崩溃不重建未确认尾段，最多丢失上一个未提交检查点后的记录。普通用户权限，读取失败不会提权。窗口标题、网页、键盘内容均不采集。

会话时长来自单调时钟，UTC 用于日期；大于 5 秒采样间隔或超过 2 秒时钟变化断开会话，留下缺口。默认 5 分钟空闲暂停，可关闭或设 1/3/5/10/15 分钟。监听锁屏、断连和睡眠/恢复；保存失败保留待重试检查点。普通 EXE 以路径摘要作为保守身份；商店应用使用包族名。ApplicationFrameHost 只接受唯一可确定的子进程包族，并重新核对复用宿主的归属，不任取第一个子进程。该宿主边界仍需实际商店应用测试；路径变化尚不自动合并。

使用本机 UUID 保存 Windows 会话；外来设备 UUID 保留，采集进度不接管。报表按选定来源设备的时区和 metric 展示；Windows 的活跃前台与 Android 的应用前台不计算混合总计。备份采用固定原始表清单、限额、摘要、外键/归属验证和事务合并；恢复前先原子保存同口令的加密保护快照到本机 Backups 目录。此版只提供合并，不提供替换删除档案。

## 尚未验收

Windows 累计按唯一会话的单调时钟时长计算。同键修订与重复恢复由主键去重；用户回拨时钟导致两个不同会话重复墙钟范围时，保留真实使用时长，日报和小时分布也保留这两段。Android 事件仍按观测区间并集，不能把两种口径混用。

当前执行环境 `GetForegroundWindow` 返回空，无法在该环境验证正常桌面前台连续计时；不把自己的 HWND 识别或合成采样当作连续采集验收。还需要在解锁的普通桌面完成 A/B 应用切换、实际空闲、锁屏、睡眠、崩溃恢复、远程断连和长时测试。未修改登录状态或绕过安全桌面。

尚未完成完整 P3：应用身份手动确认/图标、自动备份、匿名诊断 UI、完整可访问性、高 DPI 多屏、安装器与 Windows 代码签名。双向交换需要 Android v1.3.2；旧版 Android 仍拒绝 Windows 档案。WebDAV 与跨设备逻辑应用映射属于后续阶段。P3 不列为整体完成。
